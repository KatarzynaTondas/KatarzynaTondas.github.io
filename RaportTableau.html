Project description

The project was to build a one-page report presenting the main sales indicators. It was built in Tableau by Salesforce, Inc. The report focuses on key indicators such as sales, profit and number of orders, leaving out unnecessary detail to make quick decisions easier. It allows interactive filtering of the visuals with the filter panel and by selecting elements on the charts.

The interactive report is available here.

Possible extensions

The Overview page can be a base for expanding the report with additional visuals, e.g. sales growth month-over-month or year-over-year, analysis of sales data by other criteria, or a table summarising statuses and transaction details.
