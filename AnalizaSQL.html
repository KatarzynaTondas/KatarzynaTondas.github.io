COVID-19 – cases and vaccinations

A data analysis done in SQL.

  • SQL

Project description

The goal of the project was to analyse data on the COVID-19 pandemic using SQL. The study covered how the virus spread, mortality rates and vaccination progress in different regions of the world. The results provide valuable information that can support public health decisions.

The analysis with a description and the SQL code is available in the GitHub repository.

Scope of the analysis

  • Data exploration – checking the completeness and structure of the dataset.
  • Mortality rates – calculating deaths as a share of infections and identifying the regions with the highest mortality.
  • Reach of the pandemic – the share of the population infected across countries and continents.
  • Most affected areas – identifying countries with the highest infection rates relative to population.
  • Global trends – analysing daily new cases and deaths to determine the dynamics of the pandemic.
  • Vaccinations – assessing the relationship between the number of vaccinated people and the population.

Data analysis as a tool for supporting health action

The analysis gave a deeper understanding of the course of the pandemic and its impact on society. By identifying the areas with the highest infection and mortality rates, it became possible to target preventive measures and optimise health policy in the most vulnerable regions. In addition, the analysis of vaccination progress provides valuable information that can be a basis for assessing the effectiveness of vaccination campaigns and for further improving health strategies.

Why use SQL in the project
  • Efficient processing of large datasets – SQL and database engines are optimised for large datasets, so millions of records can be processed quickly, even for global pandemic data.
  • Advanced analysis – SQL supports complex queries, aggregations, filtering and statistical calculations, which makes it possible to analyse trends, compare regions and identify areas hit particularly hard by the pandemic.
  • Structured organisation of data – data is stored in relational databases, which ensures consistency, integrity and easy access to key information such as the number of infections, deaths or vaccinations by country and continent.
  • Combining different data sources – SQL makes it easy to join tables, e.g. data on infections and vaccinations, which allows analysing the relationship between the spread of the pandemic and the progress of vaccination campaigns.
  • Reusable queries and automation – SQL queries can be saved as views or stored procedures, or use CTEs and temporary tables, which makes re-analysis and report automation easier.

Data source

Kaggle dataset: COVID-19 deaths and vaccinations.
